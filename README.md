# Aimee Malan — Personal Homepage

A personal homepage and CV built with plain HTML and CSS, hosted via GitHub Pages.

## About

A single-page static site featuring a professional profile, career history, education, and contact details for Aimee Malan. 

## Stack

- HTML5
- CSS3 (no frameworks)
- Google Fonts (EB Garamond, Inter)

## Live site

[aimee-malan-personal-homepage](https://aimeemalan.github.io/aimee-malan-personal-homepage)

## Running locally

Open `index.html` directly in your browser — no build step required.
